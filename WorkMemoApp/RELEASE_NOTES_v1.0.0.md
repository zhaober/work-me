# 工作备忘录 v1.0.0（Debug）

首个可安装 Android 构建，基于 Capacitor 7 封装的单文件 HTML 应用。

## 包含功能
- 工作计划 / 日历视图 / 数据看板 / 「我的」四个主界面
- 侧边栏导航 + 底部 Tab 切换
- 浅色 / 深色主题，液态玻璃、极简、景深三种 UI 风格
- 自定义背景图上传
- 计划项优先级标记与归纳
- 交互音效、重要日子、本地数据导出

## 安装
下载 `app-debug.apk`，在手机上开启「未知来源」后安装即可（Debug 包无需签名）。
